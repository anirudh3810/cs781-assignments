# Publication notes

The original six assignment folders were copied into `assignment-01` through `assignment-06`. Originals were left unchanged. Source, notebooks, saved evaluations, supporting material and local backup versions are retained. Large files and binary artifacts are delivered through GitHub Releases to keep Git clones practical. The downloader verifies SHA-256 checksums and restores paths.

Excluded files are local virtual environments, Python bytecode/tool caches, Git metadata, private configuration, and Assignment 6 `.a6_artifacts` downloaded models and generated runtime caches. The current Assignment 6 retrieval corpus, runtime artifacts, evaluation results, human scores and final submission package are included. Any detected credential strings are redacted in publication copies; configure tokens through environment variables or notebook secrets.

This is an archival upload. Training and full assignment autograders were not rerun as part of publishing. Notebook JSON, Python syntax, public-file credentials, repository contents and release-asset sizes/checksums were checked. Existing course questions, reference notebooks and third-party materials retain their authorship; their presence does not attribute them to this repository owner.
